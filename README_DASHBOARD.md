# HDS-ROI v5.0 — Dashboard de Optimización de Portafolio Dropshipping

## 🎯 Descripción General

**HDS-ROI v5.0** es un dashboard interactivo profesional para la optimización de portafolios de hardware PC en dropshipping, integrando:

- **OE9 NSGA-III**: Optimización multiobjetivo con 7 objetivos y 24 soluciones en el frente de Pareto
- **Análisis de Datos**: Recolección, limpieza y status detallado del dataset (82 SKUs × 32 columnas)
- **Sensibilidad**: Análisis Monte Carlo con 2,000 simulaciones
- **Competitividad**: Análisis de precios internacionales vs locales
- **Modelos**: Ablación de 5 modelos de predicción (N-BEATS seleccionado)
- **Tema Blanco Profesional**: Diseño moderno y accesible
